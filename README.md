# 🍣 Sushi Lab

Videojuego 2D de simulación y gestión de
tiempo, ambientado en un universo de gatos.

El jugador administra un restaurante de sushi,
atiende pedidos, gestiona recursos y desbloquea
mejoras y minijuegos.

## Tecnologías
- Unity 6.3 LTS (6000.3.21f1)
- Universal 2D (URP)
- C#
- TextMeshPro
- Unity Input System
- Git y Git LFS

## Plataformas
- Windows
- Android
- Orientación horizontal

## Arquitectura
Assets/_SushiLab/

- Core: sistemas globales.
- Shared: recursos reutilizables.
- Features: restaurante y minijuegos.
- Settings: configuraciones propias.
- Tests: pruebas.
- ThirdParty: recursos externos.

## Minijuegos
1. Memory
2. Sushi Flappy
3. Sushi Tower
4. Tic Tac Toe

## Colaboración
Ramas por funcionalidad y Pull Requests.
Responsable de integración rotativo.

## Cómo abrir el proyecto
1. Clonar el repositorio.
2. Abrir la carpeta raíz desde Unity Hub.
3. Utilizar Unity 6000.3.21f1.
4. Esperar la importación de recursos.
